# Reporting Reference

Use concise Chinese by default when the source material is Chinese.

## Wrong Question Entry

Recommended shape:

```markdown
### 核心考点

- 我的答案：...
- 正确答案：...
- 错因：...
- 正确思路：...
- 记忆钩子：...
```

Avoid copying full proprietary question-bank content unless the user explicitly needs a private local record. Prefer paraphrased reasoning and knowledge summaries.

## Correct Question Summary

Use one sentence:

```markdown
掌握：缺铁性贫血典型表现为小细胞低色素性贫血。
```

Do not over-expand correct questions unless the user asks for a detailed review.
